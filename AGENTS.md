# Agents

## explorer

- Use: verify published Runnel versions, release assets, and checksums read-only.

## implementer

- Use: update one formula only after the corresponding release is public.
- Verify: Ruby syntax, native Homebrew installation, formula test, and diff hygiene.

## reviewer

- Use: independently compare formula URLs and SHA-256 values with the published release.
- Do not publish, retag, or replace release assets during review.
